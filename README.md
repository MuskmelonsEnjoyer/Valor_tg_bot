# Finance AI helper tg-bot

📈 Finance AI Helper Bot

Интеллектуальный Telegram-бот для управления личными финансами и мониторинга инвестиционного портфеля в Т-Инвестициях. Бот объединяет возможности официального API Т-Банка и мощь ИИ-агентов на базе LangGraph для глубокого анализа активов.

Основные возможности

    Интеграция с Т-Инвестициями: Автоматическое получение состава портфеля и текущих цен активов через API (T-Tech).

    Финансовый AI-Агент: Полноценный чат-бот на базе Gemini, который "видит" ваш портфель и может проводить анализ рынка в реальном времени.

    Гибкий импорт данных:

        Подключение через API-токен Т-Инвестиций.

        Парсинг брокерских отчетов в формате Excel (.xlsx).

    Слоистая архитектура: Четкое разделение ответственности между логикой бота, базой данных и сервисами для легкого масштабирования.

Технологический стек

    Язык: Python 3.13.9

    Telegram Framework: aiogram 3.24.0

AI Agent: langgraph, langchain, Google Gemini / LiteLLM

Database: PostgreSQL + sqlalchemy 2.0

Инвестиции: t-tech-investments (SDK для T-Invest API)
